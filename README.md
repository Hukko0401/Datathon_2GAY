# Datathon_2GAY
# Revenue Forecasting - Datathon
> Forecasting revenue and COGS for an e-commerce company based on 10 years of historical data (2012-2022)

## Overview
This project forecasts daily revenue (`Revenue`) and cost of goods sold (`COGS`) for the period **2023-01-01 to 2024-07-01** (548 days). The data consists of 14 tables related to orders, customers, products, promotions, web traffic, and inventory.

**Best Score:** RMSE ~917,000
